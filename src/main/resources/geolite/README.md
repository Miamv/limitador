# Directorio de bases de datos MaxMind GeoLite2

Colocar aquí los archivos binarios de MaxMind GeoLite2:
- `GeoLite2-City.mmdb` (Resolución de Ciudad, País, Código ISO y Ubicación)
- `GeoLite2-Country.mmdb` (Resolución de País y Código ISO - contingencia/fallback)
- `GeoLite2-ASN.mmdb` (Resolución de Número de Sistema Autónomo y Organización/ISP)

Los archivos `.mmdb` están ignorados en `.gitignore` para no saturar el historial de Git con archivos binarios de gran tamaño.
Pueden descargarse periódicamente con una cuenta gratuita en: https://dev.maxmind.com/geoip/geolite2-free-geolocation-data
